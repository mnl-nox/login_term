# Roadmap

## Fase 1 — Arquitetura
- estrutura de diretórios;
- modelo de dados;
- documentação;
- interfaces públicas;
- regras de ID e status.

## Fase 2 — Núcleo C
- User;
- UserProduct;
- UserStore;
- operações CRUD;
- validações.

## Fase 3 — Interface terminal
- menu principal;
- cadastro;
- listagem;
- busca por ID;
- atualização;
- desativação/reativação;
- gerenciamento de produtos/serviços.

## Fase 4 — Persistência
- salvar;
- carregar;
- tratamento de arquivo corrompido;
- backup;
- versão do formato.

## Fase 5 — Autenticação
- contas;
- hash de senha;
- sessão;
- papéis/permissões.

## Fase 6 — Evolução
- SQLite;
- filtros avançados;
- pesquisa textual;
- auditoria;
- relatórios.
