# Change Management

## Fluxo

Change Request → Impact Analysis → Decision → Requirement Update → Design/Architecture → Implementation → Verification → Baseline/Release

## Registro mínimo
ID, descrição, motivo, origem, requisitos afetados, stakeholders afetados, impacto em escopo, arquitetura, dados, segurança e testes, decisão e evidência de implementação.

## Exemplo
Adicionar e-mail ao User afeta domínio, validação, menu, persistência, testes, documentação e RTM. A mudança deve ser tratada como alteração de requisito, não apenas como edição de código.
