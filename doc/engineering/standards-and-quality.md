# Standards and Quality

## Referenciais
PMBOK/PMI para gerenciamento; ISO/IEC/IEEE 29148 para requisitos; ISO/IEC 25010 para qualidade; ISO/IEC/IEEE 12207 para ciclo de vida; ISO 31000 para riscos; ISO/IEC 27001/27002 para segurança.

## Qualidade
Adequação funcional, confiabilidade, segurança, manutenibilidade, testabilidade, portabilidade, desempenho quando mensurável e integridade de dados.

## Verificação e validação
Verificação: o artefato atende à especificação?
Validação: o resultado atende à necessidade?

## Definition of Done
Requisito identificável, implementação compatível, revisão, testes quando aplicáveis, ausência de regressão conhecida e documentação afetada atualizada.
