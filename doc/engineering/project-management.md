# Project Management

Este estudo de caso aplica práticas de gerenciamento de projeto ao ciclo de vida do login_term.

## Foco
Stakeholders, escopo, requisitos, riscos, qualidade, mudanças, entregas e valor.

## GitHub como governança
- Issue: requisito, tarefa, defeito, risco ou mudança.
- Branch: isolamento.
- Pull Request: revisão e integração.
- Commit: alteração rastreável.
- Release: baseline entregue.
- Project: backlog e fluxo.

## Baselines
- 0.1: requisitos e arquitetura;
- 0.2: núcleo;
- 0.3: terminal;
- 0.4: persistência;
- 0.5: testes/qualidade;
- 1.0: primeira versão utilizável.

## Definition of Done
Escopo identificável, revisão realizada, testes aplicáveis executados, regressões conhecidas tratadas e documentação/RTM atualizadas quando necessário.
